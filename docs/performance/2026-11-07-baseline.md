For a production comparison, build Next with `pnpm exec next build --profile`,
run the production server against the same API, repeat the scenario with the same
viewport and throttling, and record at least five samples. Compare cold navigation
and warm typing separately. Use `scripts/perf-snapshot.sh <API URL including /v1>`
for wire sizes and cache headers. Do not derive a worker or bundle split from this
development trace alone.

that integration for field Web Vitals; sampling must be configured in the target
